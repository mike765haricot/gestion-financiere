# CrowdSec - Analyse Stratégique & Financière 🛡️⚡

Projet académique d'analyse stratégique et financière de la start-up technologique **CrowdSec**, doté d'une interface utilisateur immersive sur le thème **Cyberpunk / Tactical Dashboard**.

## 🌐 Déploiement en Ligne
L'application est déployée publiquement et accessible à l'adresse suivante :
👉 **[https://gestion-financiere-mauve.vercel.app](https://gestion-financiere-mauve.vercel.app)**

---

## 📋 Présentation du Projet & Consignes
Ce site a été conçu pour répondre à 100 % aux exigences académiques suivantes :

1. **Choix d'une Start-up Tech (Pas de grand groupe)** :
   - Sélection de **CrowdSec**, leader français de la détection de menaces cyber collaboratives (sous-effectif, levée de fonds active).
2. **Présentation Standardisée** :
   - **Qui** : Piloté par le CEO Philippe Humeau et les co-fondateurs Laurent Soubrevilla et Thibault Koechlin. Soutien de Breega et NextStage AM.
   - **Quoi** : Pare-feu open-source collaboratif basé sur le partage communautaire d'adresses IP malveillantes en temps réel.
   - **Combien** : Équipe de 50+ personnes, levée de fonds de 5M€, modèle SaaS B2B, et Chiffre d'Affaires projeté de **1.8M€ ARR**.
3. **Justification de l'Implantation (Paris, France)** :
   - Accès aux talents du **Campus Cyber** européen.
   - Enjeux stratégiques et financiers : Conformité stricte au **RGPD** et souveraineté des données (protection face au US Cloud Act).
4. **Plan de Développement sur 3 Horizons** :
   - **Horizon 2 ans (Techno)** : Détection prédictive basée sur le Machine Learning (Zero-Day local).
   - **Horizon 5 ans (Offre)** : Lancement de la gamme "Compliance" (Prod 2) pour les normes NIS 2 et DORA dans le secteur bancaire.
   - **Horizon 10 ans (Sortie/Exit)** : Stratégie de liquidité des fonds d'investissement (Option A : IPO Euronext Paris ou Option B : Rachat Cisco/Cloudflare).

---

## 🎨 Fonctionnalités Visuelles (Thème Cyberpunk)
- **Matrix Digital Rain** : Arrière-plan animé simulant une pluie de code de sécurité hexadécimal et binaire.
- **Grille & Balayage Laser** : Overlay avec scanline verticale active (`.scanline`) et grille technique (`.cyber-grid`).
- **Composants Tactiques** : Cartes à coins coupés (`clip-path`) avec brackets lumineux interactifs lors du survol.
- **Radar Holographique** : Animation vectorielle concentrique simulant la géolocalisation de la cible d'implantation à Paris (`PARIS_TARGET`).
- **Timeline Énergétique** : Ligne chronologique animée traversée par un flux lumineux constant.
- **Indicateurs LED Clignotants** : Cartes d'exit dotées de voyants LED d'état dynamiques.

## 🛠️ Technologies Utilisées
- **Structure** : HTML5 sémantique.
- **Styles** : CSS3 Vanilla (Variables HSL personnalisées, Animations de keyframes, `backdrop-filter`, `clip-path`).
- **Logique** : Canvas API (JavaScript ES6) pour la pluie de code matricielle réactive.
- **Icônes & Typographies** : FontAwesome 6, Google Fonts (*Orbitron* & *Rajdhani*).
- **Hébergement** : Vercel.
